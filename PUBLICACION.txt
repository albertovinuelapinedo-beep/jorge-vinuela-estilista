PUBLICAR LA WEB DE JORGE VIÑUELA ESTILISTA

La web es estática y no usa React, Next.js, dependencias, claves API ni servidor propio.

1) DESCOMPRIME EL ZIP en tu ordenador.
2) En GitHub, crea un repositorio nuevo llamado: jorge-vinuela-estilista.
3) Sube los archivos y la carpeta assets a la raíz del repositorio. Es importante que index.html quede en la raíz, no dentro de una carpeta adicional.
4) Entra en Vercel y pulsa Add New > Project.
5) Importa el repositorio jorge-vinuela-estilista.
6) Deja el framework como Other (o que Vercel detecte sitio estático). No pongas build command ni output directory.
7) Pulsa Deploy.

Vercel te dará una dirección .vercel.app. Si luego conectas un dominio propio, podremos actualizar las etiquetas de SEO y el sitemap.
